# Sales Data Analysis (Superstore)

## Project Overview
This project performs exploratory data analysis (EDA) on a retail superstore dataset to understand sales, profit, and trends over time.

## Dataset
- Source: Sample Superstore dataset
- Records: 9,994
- Columns: 21

## Tools & Technologies
- Python
- pandas
- matplotlib
- Jupyter Notebook

## Key Analysis Performed
- Data loading and inspection
- Date conversion and preparation
- Missing value checks
- Total sales and profit analysis
- Sales and profit by category
- Sales trend analysis over time

## Key Insights
- Technology generated the highest sales and profit.
- Furniture had relatively low profit despite strong sales.
- Sales showed a clear upward trend in recent years.

## Files
- `superstore_sales_analysis.ipynb` – Jupyter Notebook with full analysis
- `sample_superstore.csv` – Dataset used for analysis
